# Portable Release Review

Choose an explicit release set: runnable source, required assets, fictional samples, licenses, and concise entry/verification instructions. Keep personal databases, credentials, private conversations, build caches and unrelated upstream material outside it. This task does not authorize publishing unrelated personal material.

Replace machine-specific defaults with project-relative or documented configurable inputs. Preserve attribution for reused libraries and artwork. Do not grant new blanket reuse rights to assets with a different ownership/license scope.

Check the extracted/exported copy, not only the original working tree. Verify the appropriate launch, meaningful workflow and export. State what was observed locally versus on another machine. Keep source, demo media, attachments and hosted versions synchronized; screenshots and continuous recordings should be labeled accurately.
