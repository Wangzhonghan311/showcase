# 通用工作方法与 Skills

- [保持核心的迭代](skills/frozen-core-iteration/SKILL.md)：已有规则、数据和引擎保持固定，先明确变化范围，再检查呈现与体验。
- [证据与语料工程](skills/evidence-corpus-pipeline/SKILL.md)：保全原件、登记来源与位置，把入库、检索和阅读状态分开记录。
- [业务状态验收](skills/workflow-state-acceptance/SKILL.md)：检查操作真正改变了什么，包括拒绝路径、持久化、重启和导出。
- [可见动作验收](skills/visible-motion-review/SKILL.md)：从观众看到的中心动作检验动画与内容，区分渲染完成和体验完成。
- [长期系统审计](skills/long-running-system-audit/SKILL.md)：分别验证时序、身份、恢复和设备路径，保留不同送达状态。
- [可移交的交付](skills/portable-release-review/SKILL.md)：用干净副本检查启动、素材、样例、来源与完成边界。

这些是跨项目方法的公开改写。项目专用原始 Skill、工程脚本、策略参数和经验数据库保留私有。
