# 素材、参考与授权来源

- 主参考（2026-09-18 浏览器打开并观察）：https://rokr.robotime.com/product/rokr-magic-cello-amk63/
- 产品资料参考：https://www.robotimeonline.com/products/rokr-magic-cello-mechanical-music-box-3d-wooden-puzzle-amk63
- 提炼：浅色木片与深色切面、开放齿轮组、先上弦后运转、用局部细节介绍完整器物。ROKR 是参考品牌；MUYU 没有与其关联或合作。
- 本项目未下载、复制、改标或分发参考站产品图片、视频、音乐与模型。
- 原创：MUYU 概念品牌字标与文案、所有三维几何、程序化木纹、材质和运动编排。参考物为大提琴，本作采用原创星象仪主题。
- 音乐：代码定义的原创短旋律，Web Audio 正弦谐波实时合成；不包含商业录音。
- 字体：调用设备本地 Georgia / 宋体 / Segoe UI / Microsoft YaHei 等；未分发商业字体文件。不同设备的字形可能略有差异。
- Three.js 0.180.0，MIT：https://github.com/mrdoob/three.js/tree/r180
- RoomEnvironment：来自同一 Three.js 发行版的 MIT 示例模块，用于生成本地环境光。
- esbuild 0.25.9：仅构建工具，MIT；运行时无需访问它。
- FFmpeg：用于本地录制转码；可执行文件不进入对外交付 ZIP。未生成虚构中间帧。
